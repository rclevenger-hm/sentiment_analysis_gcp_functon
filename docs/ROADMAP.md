# Roadmap

## Candidate improvements

Evaluate labels on real domain feedback; support configurable versioned threshold policies only after calibration. Add a Firestore-emulator integration suite and a separate opt-in cloud acceptance environment. Consider webhook delivery with explicit recipient configuration, signing and retry isolation. Large datasets need a separate streaming upload/batch orchestration design rather than increasing every current limit.
